## 문제 풀이

* [Level 0](./프로그래머스/0)
* [Level 1](./프로그래머스/1)

각 문제 폴더에는 문제 정보가 담긴 `README.md`와 제출한 코드가 같이 저장됩니다.

```text
프로그래머스/
├─ 0/
│  └─ 문제번호. 문제이름/
│     ├─ README.md
│     └─ 풀이코드
└─ 1/
   └─ 문제번호. 문제이름/
      ├─ README.md
      └─ 풀이코드
```

## 기록

코딩테스트 준비하면서 푼 문제들을 모아두고 있습니다.

쉬운 문제부터 빠르게 풀면서 기본기를 채우고, 이후에는 Level 2 이상 문제와 자주 나오는 알고리즘 문제들도 추가할 예정입니다.
